# Robotics & Physical AI Learning

I'm a student at San Diego State University learning how modern AI connects to the physical world: robotics, simulation, and embodied agents. This repo tracks my learning notes and small experiments.

## Goals

- Understand the basics of robot perception, planning, and control
- Learn how large language models and vision-language models can help robots reason about tasks
- Build small, reproducible projects in simulation before moving to real hardware
- Use open models through [Nebius Token Factory](https://tokenfactory.nebius.com) for inference experiments

## Planned Projects

- [ ] **LLM task planner**: turn natural-language instructions into step-by-step robot actions
- [ ] **Vision-language scene understanding**: use a VLM to describe and reason about camera images
- [ ] **Simple robot simulation**: control a robot arm or mobile robot in PyBullet or MuJoCo
- [ ] **Agent + tools demo**: connect an LLM agent to a simulated robot through a tool interface

## Tech I'm Learning

- Python, PyTorch
- Simulation: PyBullet / MuJoCo
- ROS 2 basics
- OpenAI-compatible APIs for open-weight models
